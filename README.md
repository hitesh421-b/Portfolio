# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project is a modern, responsive, and beginner-friendly portfolio built using **HTML, CSS, and JavaScript**.

The website is designed to showcase my **skills, projects, resume, and contact information** in a clean and professional way.

## ✨ Features

- 📱 Fully responsive design
- 🏠 Modern Home/Hero section
- 👨‍💻 About Me section
- 🛠️ Skills section with progress bars
- 📂 Projects showcase
- 📄 Resume download option
- 📧 Contact form with JavaScript validation
- 📍 Contact information
- 🔗 Social media links
- 📱 Responsive mobile navigation
- ⬆️ Back-to-top button
- 🔄 Smooth scrolling
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
